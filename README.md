# Open Ledger

Client-side paycheck planner. Numbers stay in the browser.

**This is not a financial advisor. This is not investment advice.** No brokerage calls. No product pitches.

## Live

After GitHub Pages is on: https://alex-caro.github.io/open-ledger/

## What it does

- Takes a biweekly net check
- Splits rent, food, car, phone, and a savings transfer
- Shows leftover dollars and leftover percent of monthly pay
- Flags when rent + food + car eats more than half of monthly take-home

## Stack

HTML, CSS, JavaScript. Local only.
